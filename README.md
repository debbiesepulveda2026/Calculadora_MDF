# Calculadora MDF Láser

Calculadora de costo, margen y precio de venta para productos de MDF cortados en láser, por unidad y por metro cuadrado.

## Qué calcula

- Costo del MDF por m² a partir del precio y la medida de la plancha (con % de merma)
- Costo por unidad: MDF + tiempo de láser + mano de obra + insumos
- Precio de venta según el margen deseado: precio = costo ÷ (1 − margen)
- Precio y costo por m², con o sin IVA (19 %)
- Piezas por plancha, aprovechamiento y planchas necesarias para un pedido
- Tabla de precios estimados para medidas comunes
- Productos guardados en el navegador
